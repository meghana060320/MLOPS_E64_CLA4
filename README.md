# ML Model Deployment Strategies and Model Serving using FastAPI

## Dataset
Use **Titanic – Machine Learning from Disaster** from Kaggle:
https://www.kaggle.com/competitions/titanic/data

Download `train.csv` and place it at `data/train.csv`. The Kaggle competition may require you to sign in and accept its rules. This project does not substitute another dataset.

## Tasks implemented
1. `train_model.py`: preprocessing, stratified train/test split, Random Forest classification, accuracy evaluation, and saving the complete pipeline to `model.pkl`.
2. `online_inference.py`: predicts one passenger record.
3. `batch_inference.py`: predicts 20 passenger records and writes `batch_predictions.csv`.
4. `streaming_inference.py`: simulates 10 incoming records with a one-second delay.
5. `app.py` and `client.py`: FastAPI `/health` and `/predict` endpoints and a Python API client.
6. `observations_report.pdf`: brief observations report.

## Run locally
```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt

# Put Kaggle's train.csv in data/train.csv, then:
python train_model.py
python online_inference.py
python batch_inference.py
python streaming_inference.py
```

## Run FastAPI
```bash
uvicorn app:app --reload
```
Open http://127.0.0.1:8000/docs. Test `GET /health`, then `POST /predict` with:
```json
{
  "Pclass": 3,
  "Sex": "female",
  "Age": 24,
  "SibSp": 0,
  "Parch": 0,
  "Fare": 8.05,
  "Embarked": "S"
}
```
For an invalid request, try `Pclass: 9` or `Sex: "unknown"`; Pydantic should return HTTP 422.
In a second terminal run `python client.py`.

## Notes on unseen records
The online record is a manually specified example not used as a training row. Batch and streaming scripts sample passenger feature records deterministically from the provided Titanic file and do not pass the `Survived` column to the model. For a strict hold-out-only demonstration, change these scripts to use a separate, untouched inference file (e.g. Kaggle `test.csv`, which has no labels) if your instructor requires it.

## Important
`model.pkl`, `metrics.json`, and `batch_predictions.csv` are generated by `train_model.py` and `batch_inference.py`.
